# bizmote オウンドメディア 運用手順書(非エンジニア向け)

このサイトは「記事を書いて、保存ボタンを押すと、数分後に自動で公開される」仕組みになっています。
プログラミングの知識は不要です。日常の運用はすべてブラウザだけで完結します。

---

## 1. 仕組みの全体像(1分で理解する)

```
Pages CMS(ブラウザの編集画面)
   ↓ 保存すると
GitHub(記事や設定のファイル置き場)
   ↓ 変更を検知して
Cloudflare Pages(自動でサイトを組み立てて公開)
   ↓ 数分後
https://bizmote.jp に反映
```

- **Pages CMS** … 記事を書く場所。ブラウザで使う無料のCMSです。
- **GitHub** … すべてのデータの保管庫。Pages CMSが裏で自動的に読み書きします。
- **Cloudflare Pages** … 公開サーバー。保存のたびに自動で最新のサイトを公開します。

---

## 2. Pages CMS の初期設定(最初の1回だけ)

1. https://app.pagescms.org/ を開く
2. **「Sign in with GitHub」** でログイン(このリポジトリ `daisukeyamaoka-bizmote/HP` にアクセスできるGitHubアカウントを使う)
3. リポジトリ一覧から **HP** を選ぶ
4. 左メニューに「記事」「お知らせ」「書き手(メンバー)」「サイト設定」が表示されれば設定完了です
   (この画面構成は、リポジトリ直下の `.pages.yml` というファイルで定義されています)

---

## 3. 記事の追加方法

1. Pages CMS を開き、左メニューの **「記事」** を選ぶ
2. 右上の **「Add Entry(追加)」** を押す
3. 各項目を入力する:

| 項目 | 書き方 |
|---|---|
| タイトル | 記事の見出し。そのままページの大見出しになります |
| スラッグ | URLになる半角英字。例:`enterprise-sales-blueprint`。**公開後は変えないでください**(URLが変わり、リンク切れになります) |
| リード文 | 一覧ページや検索結果に出る2〜3行の要約 |
| この記事の結論 | 記事冒頭の「この記事の結論」枠に表示される150〜200字。**AI検索に引用されやすくなる最重要項目なので必ず書く** |
| カテゴリ | GTM/業務の仕組み化・AI活用/起業・事業づくり から選択 |
| 書き手 | 執筆したメンバーを選択 |
| 公開日 | 記事の日付 |
| 更新日 | 後から加筆したときに入れる(未入力でOK) |
| メイン画像 | 16:9の画像をアップロード(任意) |
| 下書き | **オンにすると公開されません**。書きかけはオンにしておく |
| 本文 | 記事本体。見出し(H2)を使って構成する |

4. 右上の **「Save(保存)」** を押す → 数分でサイトに反映されます

### 記事の書き方のコツ(AI検索対応)

- 冒頭の段落で「◯◯とは△△である」と**定義から書き始める**(AIが引用しやすい形)
- 各見出しの直後に、そのセクションの**結論を1〜2文で先に書く**
- 数字・実例を入れる
- 記事末尾に「よくある質問」を付けると、AI検索・Google検索の両方に効きます

---

## 4. お知らせの追加方法

1. 左メニューの **「お知らせ」** → 「Add Entry」
2. タイトル・スラッグ・公開日・種別(プレスリリース/お知らせ/イベント/メディア掲載)・本文を入力
3. 保存すると、トップページの「お知らせ」欄と `/news/` に自動で載ります

> 現在入っているお知らせ4件は初期構築時のサンプルです。実際の内容に合わせて編集・削除してください。

---

## 5. 公開の仕組みと確認方法

- **保存=公開依頼** です。保存すると自動でビルドが始まり、**約2〜3分**で反映されます
- 反映されたか確認するには、該当ページを開いて再読み込み(Ctrl+R / Cmd+R)
- 「下書き」をオンにして保存すれば、公開せずに保存だけできます
- 間違えて公開した場合は、記事を開いて「下書き」をオンにして保存すれば非公開に戻ります

---

## 6. 書き手(メンバー)の追加・変更

1. 左メニューの **「書き手(メンバー)」** で追加・編集できます
2. 「運営元について」ページのメンバー欄に出したくない人(外部寄稿など)は、「メンバー欄に表示する」をオフに
3. **注意**:新しい書き手を追加したら、記事編集画面の「書き手」選択肢にも追加が必要です。
   これはリポジトリ直下の `.pages.yml` 内、`name: author` の `options.values` に1組(value/label)追記します。
   自分で編集が難しければ、Claude Code に「.pages.yml の書き手の選択肢に◯◯(スラッグ:xxx)を追加して」と頼めば完了します

## 7. 「私塾」名の一括置換手順(正式名称が決まったら)

起業家輩出コミュニティの名称「私塾」は仮の名前です。**サイト全体で使われる名称は1箇所で管理されている**ため、置換は1分で終わります。

### 手順(Pages CMSでやる場合・推奨)

1. Pages CMS 左メニューの **「サイト設定」** を開く
2. **「起業家輩出コミュニティの名称」** の欄を「私塾」から正式名称に書き換える
3. 保存する

これだけで、以下のすべてが自動で新名称に切り替わります:

- 「運営元について」ページの会社概要(事業内容)
- 「事業について」ページのコミュニティ名
- トップページの事業紹介欄
- AI検索向けの説明ファイル(llms.txt)や各ページのメタ情報

### 記事本文の中に「私塾」と書いた場合

記事本文は自由テキストなので、本文中に旧名称を書いた記事があれば個別に直します。
GitHub の検索(リポジトリを開いて `t` キー→検索窓に「私塾」)で該当ファイルを探すか、
Claude Code に「content/ 以下の記事本文にある『私塾』を『◯◯』に一括置換して」と頼んでください。

## 8. ドメイン設定(bizmote.jp を新サイトに切り替える)

現在のドメイン(bizmote.jp)は お名前.com で管理されています。切り替えは次の順で行います。

1. **Cloudflare Pages にプロジェクトを作成**
   - Cloudflare にログイン → Workers & Pages → Create → Pages → 「Connect to Git」
   - リポジトリ `daisukeyamaoka-bizmote/HP` を選択
   - 設定値:Production branch = `main`/Build command = `npm run build`/Build output directory = `dist`
   - デプロイ後、`xxxx.pages.dev` という仮URLで表示を確認する
2. **Cloudflare にドメインを追加**
   - Cloudflare の「Add a site」で `bizmote.jp` を登録(Freeプランで可)
   - Cloudflare からネームサーバー2つ(例:`xxx.ns.cloudflare.com`)が発行される
3. **お名前.com でネームサーバーを変更**
   - お名前.com にログイン → ドメイン設定 → ネームサーバー設定
   - Cloudflare から発行された2つに書き換える(反映まで数時間〜24時間)
4. **Cloudflare Pages にカスタムドメインを設定**
   - Pages プロジェクト → Custom domains → `bizmote.jp` を追加
   - SSL証明書(https化)は自動で発行されます
5. **切り替え完了の確認**
   - https://bizmote.jp が新サイトを表示すれば完了
   - 旧WordPressサーバーは1〜2週間様子を見てから解約する

> 補足:サイトのURLを変える場合(例:別ドメインにする)は、Pages CMS「サイト設定」の「サイトURL」も合わせて変更してください。

## 9. 画像・ロゴについて

- **記事の画像**:Pages CMS の画像アップロード欄から入れます(`public/uploads/` に保存されます)
- **メンバーの顔写真**:「書き手(メンバー)」の「顔写真」欄からアップロード(正方形推奨)
- **ロゴ**:現在は仮の文字ロゴ(SVG)です。正式ロゴができたら、
  `public/images/logo/RGB_black.svg`(ヘッダー用・黒)と `public/images/logo/RGB_white.svg`(フッター用・白)を
  同じファイル名で差し替えてください。PNGしかない場合は Claude Code に「ロゴをこのPNGに差し替えて」と依頼すればOKです
- **SNSシェア画像(OGP)**:`public/ogp.png`(1200×630px)。差し替えは同名で上書き

## 10. 困ったときは

| 症状 | 対処 |
|---|---|
| 保存したのに反映されない | 5分待って再読み込み。それでもダメなら Cloudflare Pages の Deployments でビルドエラーがないか確認 |
| 記事が表示されない | 「下書き」がオンになっていないか確認 |
| 画面が崩れた・壊した気がする | GitHub にすべての履歴が残っています。Claude Code に「◯◯を元に戻して」と依頼すれば復旧できます |
| 新しいページや機能が欲しい | Claude Code に依頼(このリポジトリを開いて指示するだけ) |

## 付録:AI検索対応(GEO)として実装済みの項目

このサイトには以下が組み込み済みです。運用で意識するのは「記事の書き方のコツ」(3章)だけで大丈夫です。

- 全ページ固有の title/description/canonical URL
- OGP・Twitterカード(SNSシェア用メタ情報)
- JSON-LD構造化データ(Organization/WebSite/Article/NewsArticle/Person/BreadcrumbList/FAQPage)
- `https://bizmote.jp/llms.txt`(AIクローラー向けサイト案内。記事を追加すると自動更新)
- `robots.txt` でAIクローラー(GPTBot/ClaudeBot/PerplexityBot等)を明示許可
- サイトマップ自動生成(`/sitemap-index.xml`)
- RSSフィード(`/rss.xml`)
- 更新日の表示と構造化データへの反映
